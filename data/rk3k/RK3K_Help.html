Alarm Panel Virtual ESP32 Keypad RK3K Interface 12 
Typical Keys (with keypad door open)
0-9, *, #, f, a, p 

Special Keys: (work with keypad door in any state)
CTRL-F  = Fire Alarm (emulates holding F for 3secs)
Shift-F = Fire Alarm (emulates holding F for 3secs)
CTRL-P  = Police Alarm (emulates holding P for 3secs)
Shift-P = Police Alarm (emulates holding P for 3secs)
CTRL-A  = Ambulance Alarm (emulates holding A for 3secs)
Shift-A = Ambulance Alarm (emulates holding A for 3secs)
CTRL-U  = Refresh Last Display State
CTRL-V  = Display Alarm Panel Interface Firmware Version
CTRL-R  = Reset Alarm Panel Interface

Application Keys:
CTRL-H | ?   = This Help Screen
Space        = Toggle Keypad Door
CTRL-D       = Toggle Debug Display
CTRL-S       = Display Test
CTRL-X | Esc = Exit Program

Mouse / Touch:
Right of Fire LED = Help Screen
Yellow LED = Toggle Keypad Door
